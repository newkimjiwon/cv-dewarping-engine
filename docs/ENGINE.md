# Engine Technical Notes

vFlat 스타일 문서 스캐너를 목표로 하는 C++ 비전 엔진의 내부 동작 기록입니다.
코드 기준: `backend/src/document_scanner.cpp`, `backend/src/scanner_config.cpp`

## 전체 파이프라인

```text
입력 이미지
  → (1) 문서 검출          detectDocumentCornersPreview()
  → (2) 실제 종횡비 복원    estimateTrueAspectRatio()
  → (3) 곡면 보정 or 투시 변환   tryCurvedDewarp() / warpPerspective()
  → (4) 후처리 (컬러/흑백/이진화)  enhanceScannedDocument()
  → outputs/ 저장 + JSON 출력
```

## (1) 문서 검출

- 성능을 위해 긴 변 1280px 이하로 축소한 preview에서 검출하고, 좌표만 원본 해상도로 환산합니다.
- 두 경로의 후보를 함께 평가합니다.
  - Canny(30, 100) + 3×3 dilation → `RETR_LIST` 윤곽선
  - Otsu 이진화 + morphology close → `RETR_EXTERNAL` 윤곽선
- Canny 임계값을 낮게 잡고 dilation으로 끊긴 엣지를 이어서, 저대비 경계(베이지 배경 위 흰 책 등)도 잡습니다.
- 4점 근사(`approxPolyDP`)는 epsilon을 기본값의 1~4배로 점차 키우며 재시도합니다. 모서리가 둥글거나 페이지가 휜 문서 대응입니다.
- 후보 스코어링: 면적 + 밝기 + 내부 균일도 + fill ratio − 이미지 경계 접촉 페널티. 책 표지보다 실제 흰 페이지 영역을 우선하기 위한 설계입니다.
- 4점 다각형과 함께 **원본 윤곽선 전체**를 보존합니다(`DocumentCandidate`). 곡면 보정 단계에서 사용합니다.

## (2) 실제 종횡비 복원 (Zhang-He whiteboard rectification)

문제: 출력 비율을 사진상 픽셀 변 길이로 정하면 기울여 찍을수록 결과가 찌그러집니다.

해법: 4개 꼭짓점의 원근 소실 정보로부터 문서의 실제 w/h 비율을 복원합니다.

- 주점(principal point)은 이미지 중심으로 가정, 좌표를 중심 기준 동차 좌표로 변환
- `k2 = ((m1×m4)·m3)/((m2×m4)·m3)`, `k3 = ((m1×m4)·m2)/((m3×m4)·m2)`
- `n2 = k2·m2 − m1`, `n3 = k3·m3 − m1`
- 초점 거리: `f² = −(n2x·n3x + n2y·n3y)/(n2z·n3z)`
- 비율: `(w/h)² = ((n2x²+n2y²)/f² + n2z²) / ((n3x²+n3y²)/f² + n3z²)`

### 퇴화(degenerate) 케이스 — 중요

`n2z = k2−1`, `n3z = k3−1`이므로, **한 쌍의 변이 이미지 평면과 평행하면**(위에서 수직으로만
기울여 찍는 가장 흔한 구도, k≈1) 초점 거리를 수식으로 추정할 수 없습니다. 이때 위 f² 수식은
0÷0에 가까워져 엉터리 값이 나옵니다(실측: 실제 f=1400인 합성 테스트에서 f=599로 오추정).

대응: `|k−1| ≤ parallelTolerance`이면 초점 거리를 스마트폰 광각 화각 기준 가정값
`f = 0.7 × 이미지 대각선`(26~30mm 환산 상당)으로 대체합니다. 추정된 f가 대각선의
0.3~3.0배를 벗어나도 가정값으로 대체합니다.

- k2, k3 모두 ≈1이면 원근이 없는 것이므로 픽셀 길이 비율을 그대로 사용
- 복원된 비율이 [0.2, 5.0] 밖이면 픽셀 길이 비율로 폴백
- 출력 크기는 측정된 픽셀 면적을 유지하면서 복원된 비율로 배분 (`√(area·ratio) × √(area/ratio)`)

### 검증 결과 (합성 테스트, A4 실제 비율 0.707)

| 구도 | 사진상 비율 | 복원 비율 |
|---|---|---|
| 45° 수직 기울임 (퇴화 케이스, 폴백 f 사용) | 1.203 | 0.709 |
| 38°+25° 복합 기울임, f=1150 (자체 추정 경로) | — | 0.707 |

테스트 픽스처: `inputs/angle_test.jpg`, `inputs/angle_test2.jpg`

## (3) 곡면 보정 (Curved Dewarp)

문제: 4점 투시 변환은 문서를 평면으로 가정하므로 펼친 책의 불룩한 페이지를 못 폅니다.

해법 (딥러닝 없이 경계 기반):

1. 투시 변환 H로 윤곽선을 직교 공간으로 이동 — 페이지가 평평했다면 경계는 출력 사각형의
   변과 일치해야 하므로, 책의 휨은 **경계 곡선의 편차**로 나타납니다.
2. 윤곽선을 코너 4개 기준으로 상/우/하/좌 폴리라인으로 분할 (`splitContourIntoEdges`).
   윤곽선 방향(시계/반시계)은 코너 방문 순서로 자동 판별합니다.
3. 각 경계의 편차를 3차 다항식으로 최소자승 피팅. 코너는 H가 정확히 사각형 꼭짓점에
   매핑하므로 양 끝 편차를 0으로 선형 보정합니다.
4. Coons patch로 내부를 보간해 41×41 메시 생성. 수식을 전개하면 편차 항만 남습니다:
   `S(u,v) = (u·W + (1−u)·devL(v) + u·devR(v),  v·H + (1−v)·devT(u) + v·devB(u))`
5. 메시를 H⁻¹로 원본 좌표에 매핑 → 좌표 맵을 출력 크기로 리사이즈 → `cv::remap` 1회.
   이중 리샘플링 없이 원본에서 바로 최종 픽셀을 뽑습니다.

### 자동 폴백

- 최대 편차 < max(2.5px, 짧은 변의 0.4%) → 평면 문서로 간주, 일반 투시 변환
- 최대 편차 > 짧은 변의 25% → 윤곽/피팅 불신, 일반 투시 변환
- 윤곽선 분할 실패(코너 순서 뒤엉킴 등) → 일반 투시 변환

### 검증 결과

원통형 휨(z = A·sin(πx/W), A=130px)을 카메라 투영으로 시뮬레이션한
`inputs/curve_test.jpg` 기준:

- 가로줄 휨(waviness): 입력 중앙값 5.5px / 최대 10px → **출력 중앙값 2.0px / 최대 3.5px**
- 기존 실사 이미지 2장(`input.jpg`, `input1.jpg`)은 편차가 임계값 미만이라 자동으로 평면 경로를 타며 회귀 없음

### 알려진 한계

- 심하게 오목한 페이지는 출력 모서리 부근에 페이지 밖 배경이 일부 포함됩니다.
  (경계가 안쪽으로 휘면 출력 사각형이 페이지 밖 영역을 덮게 됨) — 스마트 크롭으로 개선 가능
- 경계 곡선을 내부로 보간하는 방식이라, 경계는 반듯한데 내부만 접힌 페이지
  (스파인 근처 급격한 골)는 못 폅니다. 텍스트 라인 추적 또는 딥러닝(DocUNet 계열) 영역입니다.

## (4) 후처리 — 색상 모드

CLI: `./scanner <이미지> [--mode=color|gray|bw]` (기본 color)

| 모드 | 처리 |
|---|---|
| `color` | 채널별 조명 평탄화 + 언샤프 샤프닝. vFlat 기본 느낌 |
| `gray` | 흑백 변환 후 조명 평탄화 + 샤프닝 |
| `bw` | 조명 평탄화 후 adaptive threshold 이진화. 잉크 절약 인쇄용 |

조명 평탄화(`flattenIllumination`): 어두운 글자를 dilate로 지워 종이 배경(조명 분포)만
추정한 뒤 `원본 ÷ 배경 × 255`로 나눗셈. 그림자·조명 불균일이 사라지고 종이가 하얘지며,
채널별 수행이라 약한 화이트 밸런스 효과도 있습니다. 커널 크기는 해상도에 비례해 조정됩니다.

- 최종 warp 보간은 `INTER_CUBIC`, JPEG 저장 품질 95
- 글자 선명도의 근본 한계는 입력 해상도입니다. 현재 테스트 이미지(800×533)는 문서 영역이
  약 430px에 불과해 어떤 알고리즘으로도 글자를 살릴 수 없습니다. 실기기 원본(3000px+)으로
  테스트할 것.

## 설정 레퍼런스

모든 튜닝 값은 `backend/src/scanner_config.cpp` 한 곳에 있습니다. 주요 값:

| 그룹 | 항목 | 값 | 의미 |
|---|---|---|---|
| detection | cannyLow/High | 30 / 100 | 저대비 경계 검출용으로 낮게 설정 |
| detection | minimumDocumentAreaRatio | 0.1 | 문서 최소 면적 비율 |
| rectification | fallbackFocalFactor | 0.7 | 퇴화 시 f = 0.7×대각선 |
| dewarp | polynomialDegree | 3 | 경계 편차 다항식 차수 |
| dewarp | meshGridSize | 41 | remap 메시 한 변 노드 수 |
| dewarp | min/maximumDeviationRatio | 0.004 / 0.25 | 곡면 보정 발동/포기 임계 |
| scanEnhancement | backgroundDilateRatio | 0.015 | 배경 추정 dilate 커널 비율 |
| — | jpegQuality | 95 | 저장 품질 |
